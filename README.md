# rockPaperScissors

Простая реализация классической игры "Камень, Ножницы, Бумага" в виде веб-приложения. Проект создан в рамках учебного курса [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## 🎮 **О проекте**

Это браузерная версия популярной игры, где пользователь играет против компьютера. Игра ведется до 5 побед, после чего определяется общий победитель.

## ✨ **Функциональность**

- Интерактивный интерфейс с кнопками для выбора хода
- Случайный выбор хода компьютером
- Подсчет очков с отображением текущего счета
- Уведомления о результате каждого раунда
- Определение победителя матча (до 5 побед)
- Возможность перезапуска игры после завершения матча

## 🛠 **Технологии**

- **HTML5** - структура приложения
- **CSS3** - стилизация и адаптивный дизайн
- **JavaScript (ES6+)** - игровая логика и интерактивность

## 🎯 **Как играть**

- Нажмите на одну из трех кнопок: "Камень", "Ножницы" или "Бумага"
- Компьютер случайным образом выберет свой ход
- Результат раунда отобразится на экране
- Игра продолжается до тех пор, пока один из игроков не наберет 5 побед
- Нажмите "Сыграть еще раз" для начала новой игры

## 📖 **Правила игры**
- Камень побеждает ножницы (камень ломает ножницы)
- Ножницы побеждают бумагу (ножницы режут бумагу)
- Бумага побеждает камень (бумага накрывает камень)
- При одинаковом выборе - ничья
